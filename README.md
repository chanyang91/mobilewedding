# 정찬양 ♥ 문지수 모바일 청첩장

GitHub Pages 업로드용 파일입니다.

## 업로드
1. GitHub에서 새 repository를 만듭니다.
2. 이 ZIP의 압축을 푼 뒤 `index.html`과 `assets` 폴더를 repository 최상위에 그대로 업로드합니다.
3. Repository → Settings → Pages
4. Build and deployment에서 `Deploy from a branch`
5. Branch는 `main`, Folder는 `/ (root)` 선택 후 Save
6. 잠시 뒤 표시되는 GitHub Pages 주소로 접속합니다.

주의: `assets` 폴더 구조를 변경하지 마세요.
모바일 브라우저 정책상 BGM은 방문자가 BGM 버튼을 눌러야 처음 재생될 수 있습니다.
